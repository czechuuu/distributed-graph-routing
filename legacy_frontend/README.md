# Distributed Graph Routing - Frontend

Minimal web application for visualizing the distributed graph routing system. Built with React, TypeScript, and Vite.

## Features
- **Overlay Graph Visualization**: Renders nodes and edges using HTML5 Canvas.
- **Interactive**: Supports Zoom (Scroll) and Pan (Drag).
- **Mock Data**: Generates reproducible random graph data for testing.

## Setup
Prerequisites: Node.js 18+.
0. Ensure you're using the correct node version.
   ```bash
   npm --version
   ```
   ```bash
   nvm use 20 # suggested version
   ```

1. Install dependencies:
   ```bash
   npm install
   ```


## Running locally
Start the development server:
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

## Testing
Run unit tests (Vitest):
```bash
npm test
```
